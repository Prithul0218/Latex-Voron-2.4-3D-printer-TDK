# Legacy Python post-processor

`unidir_laser.py` was the first version of the post-processor. **Do not use it for printing:**
- it has the wrong-start-point bug (see `../README.md`);
- it uses the older `LASER_ON` / `LASER_OFF` macros, which can switch the laser power pin.

It is kept for the development record only. Use `../latex-laser-postprocessor.html`.
